# UI 设计规划

> 本文描述 **`ui/` 当前实现**（对齐 REQUIREMENTS.md 附录 B）。
> 初版规划中的「日期轨」已废弃，相关章节已移除。

## 主题定位

**4K 影片归档台** —— 单人使用的私人片库管理工具。内容主体是高清封面图（2184×1542，色彩浓烈），
界面的职责是**让图片发光、让信息可扫、让操作零阻力**。

用户每天面对 10–40 张卡片，核心动作只有四个：**扫一眼今天有什么 → 复制链接 → 转发下载 → 删掉不要的**。（「下载」经 MTProto 用户账号把 ed2k 发到转发目标，与手动发送同构；交互行为不变。）

## 一、设计方向：放映室 / 胶片档案

封面图本身已经足够艳丽，所以**外壳必须安静**。深墨蓝底 + 黄铜色强调，
像放映间的暗环境与设备铭牌 —— 不用纯黑（会显得廉价），不用暖米色（AI 设计重灾区）。

### 色彩令牌

| 名称 | 值 | 用途 |
|---|---|---|
| `--ink-900` | `#080A0F` | 页面底色 |
| `--ink-800` | `#0C1017` | 次级底 |
| `--ink-700` | `#121722` | 卡片底 |
| `--ink-600` | `#1A2130` | 图片占位 / 悬浮 |
| `--brass` | `#D9A441` | 黄铜强调：番号、当前日期、主按钮 |
| `--text` | `#EDEAE4` | 主文字（暖白，非纯白）14.9:1 |
| `--text-mid` | `#C2C9D6` | 次级文字 10.8:1 |
| `--text-dim` | `#99A2B2` | 弱化文字 6.9:1 |
| `--text-faint` | `#828B9D` | 最弱（仅用于非文本装饰）5.2:1 |
| `--danger` | `#E0574A` | 删除 |

> 刻意避开两个 AI 高频套路：暖米色+陶土色、纯黑+荧光绿。这里用**深墨蓝 + 黄铜**。

### 字体

| 角色 | 字体 | 理由 |
|---|---|---|
| 显示 / 日期数字 | **Bricolage Grotesque** | 有性格的变量无衬线，数字骨架独特，不落俗套 |
| 界面 / 正文 | **Instrument Sans** | 干净、微收窄，中文回落到系统字体 |
| 番号 / ed2k / 密钥 | **Azeret Mono** | 番号、API Key、Bot Token 是等宽标识符，等宽**有实际扫描价值**（不是装饰） |

三款字体各有明确分工，不重复。

## 二、设置弹窗（居中悬浮卡片）

齿轮位于**日期切换左侧**（中性色，不抢「复制」的黄铜语义）。
点击后弹出**居中悬浮卡片**：860×620，圆角 16px，`--sh-float` 大投影浮于遮罩之上。

```
┌──────────── 深色遮罩（blur 14px）────────────┐
│                                              │
│      ┌──────────────────────────────┐        │
│      │ 设置                       ✕ │        │
│      ├────────┬─────────────────────┤        │
│      │站点 ★  │  分区标题            │        │
│      │基础设置 │  说明文字            │        │
│      │网络代理 │  ┌────────────────┐ │        │
│      │Emby    │  │ 输入框          │ │        │
│      │Telegram│  └────────────────┘ │        │
│      ├────────┼─────────────────────┤        │
│      │        │        已保存  [保存]│        │
│      └────────┴─────────────────────┘        │
└──────────────────────────────────────────────┘
```

- 左栏**五个**分区（★「站点」为新增，置首），**每区只显示自己的配置项**，**每区各有独立保存按钮**
- 「站点」字段：RSS 订阅链接 / 用户名 / 密码（密码回显为占位符）
- 侧边栏底色 `rgba(0,0,0,.24)`（比卡片暗），形成内凹的导航栏

- ≤900px 卡片 760×560；≤560px 铺满且侧边栏转为**横向标签条**

## 三、设计原则

1. **图片优先**：卡片图片满出血、无内描边、无叠加装饰，信息全部退到图下方。
2. **状态可见**：卡片上的状态必须一眼可辨，不能等点了才失败。
   - 未解锁 ed2k → 降饱和 + 复制/下载禁用
   - Emby 已入库 → 图片区**左下角**标记（用户指定；绿色 + 背景模糊，见 §5.3）
3. **操作即时**：复制/删除无确认弹窗；删除后给可撤销的提示条，而不是拦截式对话框。
4. **克制的动效**：仅保留一次入场编排 + 交互反馈；尊重 `prefers-reduced-motion`。
5. **半径分级**：卡片 16px、图片 12px、芯片 999px、按钮 10px —— 不同层级不同圆角，避免「一个圆角用到底」。
6. **等宽字体只给真标识符**：番号、ed2k、API Key、Bot Token、Chat ID。访问密码是秘密不是标识符，用常规字体。

## 四、自查：避开了哪些 AI 默认套路

| 常见套路 | 本项目做法 |
|---|---|
| 暖米色 `#F4F1EA` + 陶土色 `#D97757` | 深墨蓝 `#080A0F` + 黄铜 `#D9A441` |
| 纯黑 + 荧光绿/朱红单一强调 | 墨蓝底，黄铜为主、青色为次，双色调 |
| 每个标题上方 tracked-out 全大写小标签 | 不使用 eyebrow 标签 |
| `A · B · C` 中点连接元数据 | 元数据用独立芯片 + 间距分组 |
| 所有元素同一个圆角 | 半径分 5 级（999 / 16 / 12 / 10 / 6） |
| 每张卡片同样的柔和灰阴影 | 阴影仅用于悬浮抬升与浮层，静止态用描边 |
| 编号标记 01/02/03 | 帖子非序列，不编号 |
| 按钮文字后缀 `→` | 不用箭头后缀 |
| 小数据标签一律用等宽体 | 等宽**仅**用于番号与 ed2k 这类真标识符 |

## 六、导航语义（实现时修正）

需求写「上一页 / 下一页」，但未指明方向。按中文习惯与日期序列一致，实现为：

```
◀ 上一页 = 时间上更早的归档日
▶ 下一页 = 时间上更晚的归档日
```

- 日期序列**升序**存储，默认定位到**最后一个（最新）**
- 因此进入页面时「▶ 下一页」禁用、「◀ 上一页」可用
- 键盘 `←` / `→` 与按钮同向
- 设置弹窗打开时，`←` / `→` **不得**在背后翻页（已用捕获阶段拦截）

> 初版实现为「降序 + 默认最新」，导致 ▶ 可点却走向更早的日期，与直觉相悖。
> 已改为升序。

### 月历选择器（2026-09-29 新增）

点顶栏中间的日期文本弹出**非模态月历**，可跳到任意有归档的日期：

- **只含有归档的日期可点**：无归档的日子置灰且不可交互（`<span>` 而非
  `<button>`，Tab 不可达），有归档的日子带黄铜圆点；hover 显示「N 月 N 日 周X · N 帖」
- **月份导航以数据为界**：`‹ ›` 的可用范围由归档日期的首末月份决定，
  不是自然今天——数据外不存在任何可去的月份；整月无数据仍可划过（日子全部置灰）
- **空库**：`dateList` 为空时触发按钮整体禁用，面板弹不出
- **关闭**：选中即跳转并关、`Escape` 关、点面板外部关（`mousedown` 判定，
  拖选文字不误关）；打开期间全局 `←` / `→` 翻页快捷键让位
- **数据变化同步**：采集刷新（`reloadDates`）或删除当月最后一条后，
  开着的月历实时重渲染；展示月落到数据范围之外则自动收起
- 视觉沿用现有令牌：`--brass` 选中态、`--ink-500` 置灰、`--sh-lift` 投影；
  宽 ≤560px 时改为视口宽度固定的顶部弹层

### 修复过的缺陷

| 缺陷 | 原因 | 修复 |
|---|---|---|
| 遮罩层拦截全部点击 | `[hidden]` 被 `.lightbox{display:grid}` 覆盖 | 加 `[hidden]{display:none!important}` |
| 翻页方向与直觉相悖 | 日期降序 + 默认最新 | 改升序，默认取末项 |
| 芯片标签对比度不足 | `#565F70` = 2.79:1 | 上调至 `#99A2B2` = 6.97:1 |
| favicon 404 | 未提供图标 | 内联 SVG 图标 |
| **设置弹窗打开时 ←/→ 在背后翻页** | `app.js` 的方向键监听在 document 冒泡阶段，弹窗未拦截 | 在 document **捕获阶段** `stopPropagation`（实测可阻断同节点冒泡监听），侧边栏放行 |
| **短屏下保存按钮被裁掉** | `.settings-panes` 是 `flex:1 1 0%` 但 `min-height:auto`，按内容撑破卡片后被 `overflow:hidden` 裁切 | 加 `min-height:0`，内部滚动、footer 吸底 |

### 已废弃的规划

| 项 | 说明 |
|---|---|
| **日期轨** | 初版的核心设计（刻度带可视化日期非连续），**未实现且已放弃**。相关章节、验证项、缺陷修复记录已从本文移除。当前以顶栏 `◀ 日期 ▶` + 键盘方向键导航。 |

> 而 16:9 会裁掉高度 **20.33%** —— 对封面图而言裁掉五分之一画面代价太大。

## 八、采集弹窗与后台执行

顶栏「⚙ 采集」弹出**居中悬浮卡片**（440 px，与设置面板同风格）。
配色沿用面板体系：黄铜 = 主操作（开始采集），ghost = 次操作（检查新帖/转后台/取消采集）。

### 状态图

```
                    点「采集」
        ┌──────────────────────────────┐
        ▼                              │
    ┌──────┐  开始采集/接回任务   ┌──────────┐
    │ 表单  │ ─────────────────▶ │ 进度      │
    │ form │ ◀───────────────── │ progress │
    └──────┘   终态复位/凭空消失  └────┬─────┘
        ▲         (job 消失)          │ [转后台] / Esc / 点遮罩
        │                            ▼
        │                      ┌──────────┐
        │      重开弹窗         │ 后台      │
        │ ┌──────────────────── │ background│
        │ ▼                    └────┬─────┘
    ┌──────────┐                    │ 终态到达
    │ 终态展示  │ ◀──────────────────┘（弹窗内则就地展示）
    │ (进度视图)│      Toast + reloadDates + 按钮复位
    └──────────┘
```

- **三态** `form / progress / background`：进度态与后台态共用**同一个轮询循环**，
  转后台只是关弹窗，轮询从不因视图切换而中断。
- **工具栏接管**：进度/后台两态下采集按钮呼吸（`is-running`）+ 底部 2 px
  细进度条（`#collectBar`，宽度 = 任务百分比）；后台态它是唯一可见的状态出口。
- **刷新接续**：页面加载查到 running 任务 → **静默转后台**（不弹窗、不抢焦点）。
- **重开回表单**：完成后点采集按钮 → 直接回表单（可开新一轮），备注带一句上次结果；
  后台态点按钮才恢复进度视图。
- **防误关**：进度/后台两态隐藏右上角 ✕；遮罩点击与 Esc 在采集中 = 转后台，
  终态后才恢复「点击关闭」。
- **零新增 CSS**：呼吸动画与细进度条复用既有 `styles.css`（`.btn-collect.is-running`
  + `.btn-collect-bar`），后台能力纯靠 JS 状态机。
